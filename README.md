# Roll
A geometric speedrunning platformer!

Play the progress-so-far on web / get builds [here](https://baton-0.itch.io/roll)! Soon to be on Steam (hopefully). 

View the design document (it's pretty much everything you'd want from this README) [here](https://app.notion.com/p/Roll-2f6422b876e38095b0f3dc50c0467798?source=copy_link)!

If you want to view this in the Godot editor, download Godot 4.7, clone this repo, and in Godot press import and put the path to the folder as the path.

---
## Controls
All controls can be rebound from the Options menu, accessed from the main menu, or the pause menu whilest in a level (Default P).

Default Bindings;
- Q / Space to Jump
- E / Right Click to Dash
- WASD / DPad / Arrow keys -> Perform combos while midair
- ESC / P -> Pause
- R -> Restart attempt
